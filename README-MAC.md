# Ezi Client — macOS Installation

Ezi Client is a custom Kirka.io client made by **IamEzi**.

## 🍎 macOS Requirements

- macOS 12 Monterey or newer
- Intel Mac or Apple Silicon Mac (M1/M2/M3/M4)
- Internet connection
- Kirka.io account

The macOS build is provided as a universal application, supporting both Intel and Apple Silicon Macs.

---

## 📥 Installation

### 1. Download Ezi Client

Download the latest:

**`Ezi Client 1.0.0-universal.dmg`**

from the Releases page.

### 2. Open the DMG

After downloading:

1. Open the `.dmg` file.
2. A window containing **Ezi Client** will appear.
3. Drag **Ezi Client** into the **Applications** folder.

### 3. Launch Ezi Client

Open:

**Applications → Ezi Client**

Then launch the client.

---

## ⚠️ macOS Security Warning

If macOS says:

> "Ezi Client cannot be opened because the developer cannot be verified."

This can happen because the application is not currently signed with an Apple Developer ID certificate.

If you trust the copy you downloaded:

1. Try opening Ezi Client once.
2. Open **System Settings**.
3. Go to **Privacy & Security**.
4. Scroll down to the Security section.
5. Find the message about Ezi Client.
6. Click **Open Anyway**.
7. Confirm by clicking **Open**.

You normally only need to do this the first time.

### Important

Only use this option if you downloaded Ezi Client from the official release source and trust the file.

## 🎮 Using Ezi Client

Once Ezi Client opens:

1. Wait for Kirka.io to load.
2. Log into your Kirka account.
3. Play normally.

Ezi Client is designed to provide a customized client experience for Kirka.io.

## 🗑️ Uninstall

To uninstall Ezi Client:

1. Open **Applications**.
2. Find **Ezi Client**.
3. Drag it to the Trash.
4. Empty the Trash if desired.

---

## 🔄 Updating

When a new version is released:

1. Download the newest `.dmg`.
2. Open the DMG.
3. Drag the new Ezi Client into **Applications**.
4. Choose **Replace** if macOS asks.

Your new version will replace the old application.

---

## 🛠️ Troubleshooting

### Ezi Client does not open

Try:

1. Open Ezi Client once.
2. Go to **System Settings → Privacy & Security**.
3. Look for the security warning.
4. Select **Open Anyway**.

### Ezi Client shows a blank window

Check that:

- Your Mac has an active internet connection.
- Kirka.io is accessible in your normal browser.
- You are using macOS 12 or newer.

Restart Ezi Client and try again.

### The DMG says it is damaged

Do not bypass the warning if macOS reports that an application is damaged or may contain malware.

Download a fresh copy from the official Ezi Client release instead.
